# Game of Life
This is an example of a graphical application with a simple interface based on the SDL 2.0.

## Usage:
Simple run:
```
sudo apt install libsdl2-dev
cmake -S . -B build
cmake --build build
./build/life
```
Run tests:
```
ctest --test-dir build --output-on-failure
```
Generate optimized LLVM IR (`-O2`) of the app module:
```
cmake --build build --target ir
```
or manually:
```
cd src && clang -O2 -S -emit-llvm app.c -o ../ir/app.ll
```
If SDL2 is not installed, CMake downloads and builds it automatically (internet and git are required). Tests do not need SDL.

## Controls:
Mouse click spawns an R-pentomino under the cursor.

## Graphical Interface:
```
#define SIM_X_SIZE 1536
#define SIM_Y_SIZE 768

void simFlush();
void simPutPixel(int x, int y, int argb);
int simRand();
int simHasClick();
int simGetClick();
```

## IR trace pass and pattern statistics

`pass/TracePass.cpp` is an LLVM Pass (new PM) that instruments the `-O2`
IR of `app.c` with calls to `traceEdgeLogger(user_opcode, operand_opcode)`
before every non-phi User, once per Instruction operand.  `pass/log.c` is
the runtime sink.  Collect stats with one command (needs `llvm`, `clang`,
`python3`):
```
./scripts/collect_stats.sh
```
It builds `build/libTracePass.so`, compiles `build/life_trace` with
`-fpass-plugin=libTracePass.so` on `src/app.c` + `trace/driver.c` +
`pass/log.c` (no SDL needed), runs it for `TRACE_FRAMES` frames (default
2, override with `TRACE_FRAMES=N`), writes `trace/trace.log`, then runs
`scripts/analyze.py` to produce `stats/patterns.txt` with the top n-grams
for window length 1..5.

## Files:
```
src/app.c          - logic of the game (only void app())
src/sim.c/.h       - SDL 2.0 interface
src/start.c        - main
ir/app.ll          - optimized LLVM IR of app.c
tests/             - tests with a mock of sim.h
pass/TracePass.cpp - LLVM Pass plugin (OptimizerLast, logs User<-Operand edges)
pass/log.c         - runtime sink (traceEdgeLogger)
trace/driver.c     - headless stubs for sim.h, bounded by TRACE_FRAMES
scripts/analyze.py - n-gram counter for windows 1..5
scripts/collect_stats.sh - one-shot: build pass, run, analyze
stats/patterns.txt - top n-grams (generated by scripts/collect_stats.sh)
```
